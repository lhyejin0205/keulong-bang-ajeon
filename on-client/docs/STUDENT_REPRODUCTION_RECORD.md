## 현재 코드 계약과 보존 범위

- `student/extension.mjs`의 `createStudentView()`는 인자를 받지 않습니다. 생성된 객체의 `renderIdentity`, `renderDecision`, `renderEvents`, `renderStatus`, `renderVulnerabilities`, `renderAiConnection`, `renderExplanation`, `renderAction` 메서드가 각 화면 입력을 받습니다.
- 화면 입력에는 상태별 `status`, 연결 상태 `mode`, 응답 `data`, 오류 `error` 등이 포함될 수 있습니다. `demo`는 예제 자료이고 실제 연결이 아닙니다.
- `student/engine-adapter.mjs`의 기본 내보내기는 `disconnected`입니다. 실제 연결은 별도로 준비된 호스트가 제공해야 합니다.
- 문서에서 확인한 지원 경계상 19단계 실제 보안 조치 집행 연결은 아직 준비되지 않았습니다. 본 기록에서는 실행하거나 요청하지 않았습니다.
- 코드 복구는 원본 폴더를 덮어쓰지 않고 선택한 커밋을 별도 폴더에 다시 checkout 하는 방식으로 합니다. 저장소에 커밋되지 않은 파일은 clone으로 복원되지 않습니다.
- 인증·설정 파일은 프로젝트 밖에서 별도 관리합니다. 이 파일의 복원·이전은 수행하지 않으며, 인증 정보나 비밀값을 백업하거나 기록하지 않습니다.
- 서버가 보유하는 실제 접속·보안 기록의 백업·복원은 이 저장소로 확인할 수 없고, 이번에 수행하지 않았습니다. 앱 자체의 영속 사용자 데이터 백업·복원도 미확인입니다.

### 데이터 종류별 저장·보존·복원

다음은 현재 저장소의 코드와 문서에서 확인한 범위입니다. 서버나 별도 PC의 실제 저장 상태를 조사하거나 백업·복원 실행을 검증한 결과는 아닙니다.

Windows 프로필이나 보관소 손실 시의 운영 복구는 이 기록에서 검증되지 않았으므로 담당자에게 문의합니다. |
| 별도로 제공된 `.env`·SDP 설정 및 비밀 | 프로젝트 밖의 담당자 지정 위치입니다. 실제 파일의 존재·경로·내용은 확인하지 않았으며, `.env.example`은 비밀 없는 견본입니다. | 이 프로젝트는 비밀 설정의 백업·복원 기능을 제공하지 않습니다. 파일을 Git·제출물·공유 폴더에 넣거나 내용을 기록하지 않습니다. 필요하면 담당자에게 안전한 재발급·복구 절차를 요청합니다. |

문제가 생기면 원본 프로젝트와 설정 파일을 지우거나 덮어쓰지 말고 앱을 종료한 뒤, 커밋된 코드만 별도 새 폴더에 복원합니다. 미커밋 변경이나 외부 기록·설정이 필요하면 원본을 그대로 보존하고 담당자에게 안전한 백업·복원 방법을 확인합니다. 비밀·자격 파일을 임의 복사하거나 복구용으로 Git에 추가하지 않습니다.
